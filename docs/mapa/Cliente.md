# Cliente
Persona o empresa que compra. Tabla `clientes`.
- Tiene muchos [[Prospecto]] (pedidos), cada uno puede terminar en [[Orden de trabajo]].
- Ficha: datos de contacto, origen (referido, Instagram, WhatsApp, showroom), historial de trabajos con fecha, precio, margen.
- KPIs: total de clientes, trabajos por cliente, facturación y margen acumulados.
