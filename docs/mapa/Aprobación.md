# Aprobación
El cliente acepta la [[Cotización]]. Función `aprobar_proyecto`.
- Fija el precio vendido (sin IVA).
- Crea la [[Orden de trabajo]] con despiece y lista de materiales (placas por color) y horas estimadas por etapa, editables por una persona.
- Recién acá el trabajo entra al taller (lista, Gantt, calendario) con fecha de entrega.
